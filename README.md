# Romy Health

Een persoonlijke, mobile-first health- en trainingsapp met rustige roze vormgeving.

## Privacy
Persoonlijke gegevens worden **niet** in deze GitHub-repository opgeslagen. Ingevoerde voeding en afgevinkte trainingen staan lokaal in de browser via `localStorage`.

## Functies in v1
- Vandaag-dashboard
- Trainingen per week afvinken
- Voeding registreren: kcal, verzadigd vet, zout, eiwit, suiker en vezels
- Voedingsgeschiedenis
- Voortgangsscherm voorbereid voor weekdata
- Lokale JSON-backup exporteren/importeren
- PWA/offline basis

## Publiceren met GitHub Pages
1. Open deze repository op GitHub.
2. Ga naar **Settings → Pages**.
3. Kies bij **Build and deployment**: `Deploy from a branch`.
4. Selecteer branch `main` en map `/ (root)`.
5. Klik op **Save**.

Na publicatie staat de app normaal op:
`https://meesterlijkecarsfans-byte.github.io/romy-health/`

Op iPhone kun je de pagina in Safari openen en via **Delen → Zet op beginscherm** als app installeren.
